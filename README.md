# Combined Events Calculator

App for calculating combined‑events points (Decathlon, Heptathlon, Pentathlon) built with React Native + Expo. Available on IOS, Android and Web.

## Features

- Men’s Decathlon, Men’s Heptathlon, Women’s Heptathlon and Women’s Pentathlon points calculators
- Save scores
- Visualize your performance with a bar chart
- World Athletics rankings calculator
